# Vyom Ludo

A colorful browser-based Ludo game built for local pass-and-play sessions.

## Features

- 2 to 4 player setup
- Custom player names
- Classic Ludo movement rules
- Safe tiles and captures
- Winner popup when the match ends
- Simple pass-and-play flow with inline turn messaging

## How To Play

1. Open `index.html` in your browser.
2. Choose the number of players.
3. Enter player names.
4. Start the match and use the on-screen `Roll Dice` button to play.

## Project Files

- `index.html` - app structure
- `style.css` - visual design and layout
- `script.js` - board rendering and game logic

## Notes

This project is a static frontend app and does not require a build step or dependencies.
